# 归藏术语表（界面文案的唯一标准，v2）

原则：说人话。名词用日常词，动作说全主谓，状态用结果词；每个界面词都带英文对照（中英双语显示）。内部数据键（state=draft/final 等）不改，只改给人看的名字。

## 导航（侧栏）

| 旧称 | 新中文 | English | 是什么 |
|---|---|---|---|
| 收件箱 | 待处理 | To Review | 刚生成或刚改动、等你拍板的文件 |
| 资产库 | 全部文件 | All Files | 归藏登记过的全部文件 |
| 定稿库 | 正式文件 | Final Files | 已被你定为正式版的文件，对外只用这些 |
| 存储节点 | 存放位置 | Storage | 文件实际存在哪些盘/机器/NAS 上 |
| 清理中心 | 重复文件 | Duplicates | 内容相同或近似的多余副本，确认后可清 |

## 状态（文件现在算什么数）

| 旧称 | 新中文 | English | 含义 |
|---|---|---|---|
| 草稿 | 草稿 | Draft | 还在改，不算数 |
| 候选 | 备选版 | Candidate | 几个版本之一，等你挑 |
| 定稿 | 正式版 | Final | 你已拍板，对外就用它 |
| 已发布 | 已发布 | Published | 已经发出去/交付过的正式版 |
| 已归档 | 已归档 | Archived | 不再动的旧文件 |

## 动作与区域

| 旧称 | 新中文 | English |
|---|---|---|
| 晋升定稿 / 升级 | 设为正式版 | Set as Final |
| 版本线 | 历史版本 | Version History |
| 物理分布 | 存放在哪 | Stored In |
| 它从哪来 | 来源 | Source |
| （所属）对话 | 来自哪次对话 | From Conversation |
| 生产批次（推断） | 同一批生成的文件（推断） | Same Batch (Inferred) |
| 即时搜索 | 搜索文件名或内容 | Search name or content |
| 在 Finder 中显示 | 在 Finder 中显示 | Show in Finder |

## 用词纪律

- 不用「资产、节点、晋升、定稿、来历」这类行话做界面词；它们只出现在技术文档里
- 英文不是翻译腔：用 Final / Draft / Duplicates 这类英语软件里的日常词
- 推断出来的信息必须带「（推断）(Inferred)」，不冒充记录
